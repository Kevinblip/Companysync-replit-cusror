---
name: Manager assignment surface
description: User-approved scope for manager assignment and reminder enhancements.
---

Expand the existing My Assignments, Tasks, and Reminders experiences without introducing new pages, tabs, menu items, or navigation entries.

**Why:** The user explicitly rejected additional navigation and asked to expand what the product already has.

**How to apply:** Put employee, work-type, and urgency controls inside the existing screens. Use existing task detail/reminder controls for handoffs; never grant manager access from a person's name or a job-title string.
