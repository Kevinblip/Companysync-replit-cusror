---
name: Symbility print visual target
description: Approved visual direction for the Symbility/CoreLogic estimate export.
---

Symbility exports should emulate the CoreLogic worksheet presentation rather than use a generic contractor-report layout: a dark claim banner and gray insured header on the cover, blue-gray hierarchy bars, compact table headers, blue identifiers, and subtle gray amount-cell shading.

**Why:** the product’s Symbility output must be immediately recognizable to carriers and adjusters familiar with Claims Workspace print estimates.

**How to apply:** retain the established calculation and export data rules, but use this visual system for future Symbility pages, sections, and supplemental forms.
