# Price List Bulk Import Authorization

`bulkImportPriceList` (bulk-deletes + bulk-writes a company's `PriceListItem` rows, used by the CSV/paste importer on the Integration Manager page) previously trusted a client-supplied `company_id` with no membership check — any authenticated caller could overwrite another company's pricing data. It does not call an AI model, so this was tracked separately from the AI Systems Audit and has since been fixed: it now resolves the caller via `getUserFromRequest(req)` and requires the caller be a platform super-admin OR a member of the target company (owner via `companies.created_by`, or a `staff_profiles` row scoped to it), mirroring the `bulkGeocodeEntities` strict-authz pattern. Non-members get an authorization error instead of a silent write. Flows through the same shared `vite-functions-plugin.js` handler registry for both dev and prod (no duplicate interceptor in `db/prod-integrations.cjs`).
